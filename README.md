# 📸 SnapStudy AI

SnapStudy AI is an AI-powered study assistant built with Streamlit and Google Gemini.

Students can upload a question, diagram, notes, or image, or simply type a question. SnapStudy AI then provides a simple, student-friendly explanation.

## ✨ Features

- 📚 Explain study questions in simple language
- 📸 Upload images, diagrams, and notes
- 🤖 AI-powered explanations using Google Gemini
- 📝 Step-by-step explanations
- 💡 Examples and easy summaries
- 🎓 Designed for student learning

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- Google GenAI Python SDK
